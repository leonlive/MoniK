Взимане от телефона с ADB

Това вече не е отделно “връзване”. MoniK Android app прави Tuya login-а и записва export JSON. Този server взима export-а от инсталираното приложение през ADB и го импортва в MoniK.

Правилен ред:
  1. Телефонът е вързан с USB и USB debugging е разрешен.
  2. MoniK app вече е инсталиран и е направил Tuya SDK login.
  3. MoniK app записва devices export JSON в app storage.
  4. Този server чете файла през adb shell run-as и импортва devices.

Yandex RAW схема + безопасни JSON бутони

Първо прави read-only GET към Yandex RAW devices, строи пълна схема по capabilities/properties, после показва JSON preview и реални ИЗПЪЛНИ бутони. Команди се пращат само ако ти натиснеш ИЗПЪЛНИ.

Web scanner: Yandex + Strato + LAN 6668

Read-only scan: работи и без Yandex/Strato — сканира LAN, показва IP + MAC, проверява порт 6668, а при наличен Strato snapshot добавя local key за ON/OFF. Не записва нищо в Strato, телефона или Android проекта.
